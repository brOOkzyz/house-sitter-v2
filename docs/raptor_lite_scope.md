# RaPToR-Lite: A Capability-Grounded Task Creation and Verification Layer for ROS 2 Robots, Evaluated through a House-Sitter Application

## Objective

Allow users to create structured robot tasks, verify them against the robot's declared capabilities and safety constraints, execute only approved tasks, and record reproducible evidence.

Main application: idle-time House-Sitter monitoring.

Phase 1 scope: capability registry, task schema, verifier, mock executor, execution artifacts, CLI, and tests.

Non-goals: a complete RaPToR platform; unrestricted code generation; runtime LLM control; Nav2/SLAM research; multi-robot support; automatic ROS installation; visual programming; and physical robot validation.

Provisional research questions: RQ1 verifier effectiveness; RQ2 natural-language plan reliability; RQ3 randomized House-Sitter case-study reliability.
